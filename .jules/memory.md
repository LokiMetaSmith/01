## Archived: 2026-10-31

- The repository is the **01 Project**, building an open-source ecosystem and operating system for AI conversational devices.
- Features the **01 Light** (ESP32-based voice interface) and **01 Server** running locally or via cloud.
- Built on top of `open-interpreter` to provide a code-interpreting language model.
- Exposes a speech-to-speech websocket (localhost:10001) using Streaming LMC (Language Model Computer) format.
- Includes dynamic system messages, LMC Messages format extending OpenAI's message format to include a "computer" role.
- Project goals: build physical devices, standardize LMC protocols, and expand the hardware/software ecosystem (e.g., Jetson, Pi).
